# 📓 Personal Portfolio Website

A personal portfolio designed to look and feel like a Jupyter Notebook, built from scratch with **HTML, CSS, JavaScript and Chart.js**.

🌐 **Live Demo:** [myportfoliosite-self.vercel.app](https://myportfoliosite-self.vercel.app/)

Every section of the portfolio is a notebook cell. Each one has a code input and an output, so my projects, skills and certificates show up as if I had just run them.

## Features

- **Notebook-style interface:** `In [ ]:` / `Out[ ]:` cells with run counters that fill in as cells execute
- **Interactive controls:** per-cell Run buttons, Run All, and Restart to replay the whole notebook
- **Loading screen:** a notebook-style start-up screen that crossfades into the page
- **Fake kernel status:** the status indicator switches between Idle and Busy while cells run
- **Data visualizations:** pie, bar and radar charts made with Chart.js
- **Projects as a DataFrame:** my projects are shown in a pandas-style table
- **Certificates gallery:** clickable certificate images
- **Two themes:** light mode and a pink dark mode, with the choice remembered between visits
- **Responsive design:** works on desktop and mobile
- **Accessibility:** respects reduced-motion settings

## Tech Stack

- HTML5
- CSS3
- JavaScript (vanilla)
- [Chart.js](https://www.chartjs.org/)
- Deployed on [Vercel](https://vercel.com/)
